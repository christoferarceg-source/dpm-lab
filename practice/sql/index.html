List the deals we actually won

Intro

The deals table has one row per sales opportunity, with a stage column.

Return the deal_id, account_id, and amount of every deal whose stage is closed_won, ordered by deal_id.

Why this matters for a data product

Filtering to closed_won is the first step of the Functional metric #deals_closed_value. Before you can trust an aggregate, you should be able to see the exact rows feeding it.
