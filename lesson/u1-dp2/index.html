Concept

What's inside, and the three kinds

Anatomy: input contracts, transformations & semantics, quality signals, metadata, embedded governance. A canonical core (authoritative entities and metrics) with output projections per consumer: an API for operations, tables for analytics, auditable extracts for compliance. The core never changes; projections adapt. Types: source-aligned (expose a domain faithfully), aggregate (encode cross-domain logic like how revenue is calculated), consumer-aligned (built for one use case's latency, interface, and guarantees).
